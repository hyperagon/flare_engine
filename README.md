# Famification of [Flare Engine](https://flarerpg.org/) mods
These are for:
- [Alpha Demo](https://flarerpg.org/content/mods/flare_alpha_demo.html)
- [Empyrian Campaign](https://dorkster.itch.io/flare)

Just add the respective *fam.txt* to *npcs* and replace the file in *maps*.  
Afterwards you will find `Fam, Cheater` in the respective mod selling several items, including developer ones that I found.

While I tried to let her sell a lot of items if the list goes over the limit the game crashes so I only left the magic related ones.
