# Famification of [Flare Engine](https://flarerpg.org/) mods
These are for both the [Alpha Demo](https://flarerpg.org/content/mods/flare_alpha_demo.html) and the [Empyrian Campaign](https://dorkster.itch.io/flare), just add the *fam.txt* to *npcs* and replace the file in *maps*.

After these files are applied you will find *Fam* in the respective mod selling several items, including developer ones that I found.
